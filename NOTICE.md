# Name and branding

The PhotoSpec **source code** is MIT licensed. You may use, modify, distribute
and sell work based on it, see [LICENSE](LICENSE).

The **name "PhotoSpec", the logo and the site branding are not part of that
licence.** Copyright and trademark are separate things, and the MIT licence
grants rights to the code only.

So, if you fork this project:

- **Please do** use the code for anything, including commercially.
- **Please do not** publish your fork under the name PhotoSpec, or use the logo,
  favicon or site branding in a way that suggests your version is this project or
  is endorsed by it.
- **Please do** say your work is *based on* PhotoSpec, and link back here. That
  is accurate and welcome.

This is the same position taken by most open-source projects with a name worth
protecting, and it exists so that people searching for PhotoSpec find PhotoSpec.

## A note on advertising

This project takes no money, shows no advertising, sets no cookies and uploads
nothing. That is not incidental, it is the reason the tool is trustworthy with a
photograph of your face.

The MIT licence permits someone to fork this and run an ad-funded copy, and
nothing here prevents that. But an ad-funded copy cannot honestly make the claim
that is printed at the bottom of every page of this one, and that difference is
the point.

If you are reading this because you are deciding whether to trust a site that
looks like PhotoSpec: the original lives at the repository linked from this file,
and it is the only version its author maintains.
